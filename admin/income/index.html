Royalty Management

Akun member

Pilih member dulu (bisa dicari lewat email, nama, atau nama artis). Berlaku untuk Artist Earnings, Revenue Recap, dan Payment.

Input royalty artis

Isi nominal final hak artis (setelah bagi hasil), bukan pendapatan kotor. Ketik angka saja, titik ribuan otomatis. Satu artis boleh punya beberapa entri di periode yang sama (misalnya dari agregator berbeda): isi kolom "Tambah entri baru" dan entri lama tidak berubah. Entri yang terkunci di pembayaran Pending tidak bisa diubah.

Pilih member untuk menampilkan artisnya.

Filter & rekap royalty

Lihat artis siapa dapat berapa, di bulan apa. Setiap laporan ditampilkan sendiri dengan statusnya masing-masing, tidak digabung.

Pilih member.

Riwayat input per periode

Edit memuat periode ke form di atas. Hapus menghapus semua data periode itu (kecuali yang terkunci di pembayaran Pending).

Pilih member.

Tambah rekap

Pilih file rekap dari perangkat kamu. Format: xlsx, xls, csv, zip, rar, 7z, atau pdf. Maksimal 25 MB. File otomatis dikirim ke folder report di GitHub. Link aktif setelah deploy selesai (biasanya 1-2 menit).
